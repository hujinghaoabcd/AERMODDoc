## 2.2 关键字/参数方式说明

AERMOD 的输入控制文件采用关键字/参数方式指定模型运行选项和输入数据。组成控制文件的描述性关键字和参数，可以看作一种命令语言：用户通过它告诉模型某次运行需要完成什么任务。

关键字说明输入文件每一行所提供的选项或数据类型。本手册经常把控制文件中的一行或一条记录称为一张“卡片”（card），通常以该记录的主关键字命名。

关键字之后的参数用于定义：

- 具体选择的选项；
- 实际输入数据。

部分参数本身也使用描述性的次级关键字输入。

控制文件按功能分为若干“路径”（pathway）。每行开头用两个字符的路径 ID 标识所属路径。各路径及输入顺序如下：

```text
CO - 总体运行控制选项（COntrol）
SO - 污染源信息（SOurce）
RE - 受体信息（REceptor）
ME - 气象信息（MEteorology）
EV - 事件处理（EVent）
OU - 输出选项（OUtput）
```

> 原文称控制文件分为“五个功能路径”，但随后实际列出了 CO、SO、RE、ME、EV 和 OU 六条路径。译文按原文保留这一表述和列表。

输入控制文件的每一行由三部分构成：

1. 路径 ID；
2. 8 字符关键字；
3. 参数列表。

例如：

```text
Column:  1234567890123456789012345678901234567890

         CO MODELOPT DFAULT CONC
         │  │        └──────── 参数
         │  └───────────────── 8 字符关键字
         └──────────────────── 2 字符路径 ID
```

以下说明控制文件的结构规则，以及采用关键字/参数方式的优点。

### 2.2.1 构建输入控制文件的基本规则

虽然 AERMOD 控制文件允许用户灵活安排输入结构，但仍必须遵守若干基本语法规则。这些规则的目的包括：

- 使不同用户建立的输入文件保持一定一致性；
- 简化模型对输入数据的错误检查；
- 在输入顺序影响解释时，确保信息按正确顺序提供给模型。

最基本的规则之一是：同一功能路径的全部输入必须集中在该路径内，并按照规定的路径顺序出现。即：

1. CO 路径输入最先；
2. 然后是 SO 路径；
3. 之后依次输入其他路径。

每条路径以 `STARTING` 关键字开始，以 `FINISHED` 关键字结束。因此：

- 每个输入文件的第一条功能记录必须是 `CO STARTING`；
- 最后一条记录必须是 `OU FINISHED`。

两者之间的控制文件命令用于定义该次运行的选项和输入数据。

从 09292 版本开始，模型把输入控制文件中的每条记录读作一个最长 512 字符的输入行。每条输入行由以下字段组成：

- `pathway`：路径；
- `keyword`：关键字；
- 一个或多个 `parameter`：参数。

同一行中的各字段之间至少要有一个空格。

为便于模型解释，控制文件推荐按以下列位置组织：

- 第 1—2 列：两字符路径 ID；
- 第 4—11 列：八字符关键字；
- 第 13 列至行末：参数；
- 每行最长 512 字符。

对于大多数关键字，关键字之后参数的顺序非常重要。只要参数之间至少有一个空格，并且整行不超过 512 字符，参数之间的精确空格数通常不重要。

字母可以使用小写或大写输入。模型在内部会将所有字符输入转换为大写，但标题字段和文件名除外。本指南统一使用大写形式表示关键字。

所有数值输入默认采用公制单位，例如：

- 长度：米；
- 速度：米/秒；
- 温度：开尔文；
- 排放速率：克/秒。

少数情况下，用户可以使用英尺输入长度，模型会自动转换为米。这些例外包括：

- 高地形受体高度；
- 风速仪高度。

这些数据在实际资料中经常以英尺提供。

部分关键字为必需关键字，必须出现在每个控制文件中。例如 `MODELOPT` 用于确定模拟选项。另一些关键字为可选关键字，仅在启用特定功能时使用，例如输入旗杆受体高度。

关键字还可分为：

- 可重复关键字，例如污染源参数关键字；
- 不可重复关键字，即只能出现一次。

关键字说明见第 3 章和附录 A。

除少数例外外，同一路径内部关键字的顺序通常不重要。需要注意的例外包括：

- 在 SO 路径中，必须先使用 `LOCATION` 定义某个污染源，之后才能用其他关键字引用该污染源；
- `SRCGROUP` 必须是 `SO FINISHED` 之前的最后一个关键字；
- 如果 `MODELOPT` 中指定了 `PSDCREDIT`，则以 `PSDGROUP` 取代 `SRCGROUP`；
- 对于 SO 路径中可接受一段污染源 ID 范围的关键字，其参数只会应用于此前已经定义的污染源，不会应用于输入文件后面才定义的污染源。

参数 `ILEN_FLD` 用于规定控制文件中单个字段的最大长度，并声明所有文件名和格式变量的长度。从 09292 版本开始，其值为 200，位于 `MODULES.FOR` 文件的 `MODULE MAIN1` 中。

### 2.2.2 关键字方式的优点

与某些模型采用多个数字开关并要求固定格式输入相比，关键字方式具有明显优点。

首先，关键字可以直观描述某次运行使用的选项和输入。审核人员阅读输入文件时，更容易判断该次运行执行了哪些操作。

其次，只要遵守前述少量基本规则，用户可以灵活组织输入内容，提高文件的可读性和易理解性。

AERMOD 还提供了一些增强控制文件灵活性的机制：

- **允许空行。** 用户可以用空行分隔不同路径，或将一组同类记录（如污染源位置）与其他记录分开。
- **允许注释行。** 如果路径字段中写入 `**`，模型将忽略该行。这一功能特别适合给污染源参数记录添加列标题。
- **可以临时注释掉某些选项。** 用户不必删除选项及相应数据，例如高地形高度，只需在相应行的路径字段写入 `**`。

由于关键字具有描述性、输入结构又较灵活，修改已有控制文件以获得所需结果通常比较容易。

模型内置了详细的错误处理功能，这也是其易用性较高的重要原因。模型会说明某次运行中发现的每个错误的位置和性质。

模型不会在遇到第一个输入错误时立即停止，而是会继续读取并尽可能处理全部输入记录，然后报告发现的所有错误。如果存在致命错误，模型不会继续执行扩散计算。

## 2.3 法规默认模拟选项

法规默认选项通过 CO 路径中的 `MODELOPT` 关键字控制。顾名思义，该关键字负责选择模拟选项。

`MODELOPT` 是：

- 必需关键字；
- 不可重复关键字；
- 理解和控制 AERMOD 运行方式的核心关键字。

除非用户通过其他关键字选项作出不同设置，AERMOD 默认采用以下选项：

- 使用需要输入地形高度数据的高地形算法；
- 使用烟囱顶端下洗，但建筑物下洗情形除外；
- 使用静风处理程序；
- 使用缺测数据处理程序；
- 对城市污染源 SO₂ 的指数衰减采用 4 小时半衰期。

> 从 AERMOD 18081 版本开始，无论是法规默认应用还是非法规应用，城市 SO₂ 污染源均默认采用 4 小时半衰期。

在 `MODELOPT` 关键字之后用于指定选项的参数是字符串，称为**次级关键字**。这些字符串直接描述所选择的选项。

例如，为确保某次模拟使用上述法规默认选项，用户应在 `MODELOPT` 输入中加入次级关键字 `DFAULT`。

模型开始运行时首先读取控制文件，检查所指定选项之间是否存在冲突。在多数情况下，如果发现冲突，模型会输出错误消息通知用户，并在开始模拟之前终止运行。

对于法规模拟，强烈建议设置 `DFAULT`，以确保：

- 采用法规默认选项；
- 不会使用非法规选项。

除上述默认法规选项外，AERMOD 还提供若干取决于具体应用的其他法规选项。这些选项必须由用户在控制文件中明确设置，其中多数可通过与 `MODELOPT` 相关的次级关键字启用。`MODELOPT` 的详细说明见第 3.2.2 节。

本指南尽量明确区分：

- 可以与 `DFAULT` 同时使用、但必须由用户明确设置的法规选项；
- 不能与 `DFAULT` 同时使用的非法规选项。

后一类选项有时称为 **non-DFAULT 选项**。
