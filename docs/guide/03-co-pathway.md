# 3.2 CO 控制路径：概述与标题信息

> 对应 EPA 2023版用户指南第3章 CO路径完整译文。控制文件关键字、次级关键字、参数名、文件名和模型语法保留英文；法规应用应以EPA英文原文及当前模型版本为准。

CO（Control）路径包含对整个模型运行进行总体控制的关键字，包括扩散选项、平均时间选项、地形高度选项及其他控制功能。

CO 路径必须是输入控制文件中的第一个功能路径。

<a id="co-3-2-1"></a>
## 3.2.1 标题信息

用户可以通过两个关键字指定最多两行标题，这些标题将显示在模型主输出文件的每一页上：

- `TITLEONE`：必需；
- `TITLETWO`：可选。

**语法：**

```text
CO TITLEONE Title1
CO TITLETWO Title2
```

**类型：**

- `TITLEONE`：必需，不可重复；
- `TITLETWO`：可选，不可重复。

`Title1` 和 `Title2` 均为长度最多 200 个字符的字符型参数，从第 13 列开始作为一个完整字段读取。标题按其在控制文件中出现的原样读取，不会自动将小写字母转换为大写字母。

若控制文件中未包含 `TITLETWO`，输出文件中的第二行标题将为空。需要注意的是，在输出文件中，`TITLEONE` 和 `TITLETWO` 均只打印前 68 个字符。
