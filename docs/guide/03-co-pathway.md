# 3.0 详细关键字参考：CO 控制路径

本章对 AERMOD 模型的全部输入关键字选项提供详细参考，其内容比第 2 章“简明教程”更加完整。由于本章主要面向有经验的模拟人员，旨在帮助用户全面理解各项选项在模型中的具体实现方式，因此每个关键字的说明原则上均可独立阅读。

本章假定读者已经基本理解 AERMOD 使用的关键字/参数输入方式。初学者应先阅读第 2 章，以掌握控制文件的基本结构和语法。

## 3.1 概述

本章内容按照功能组织，即将关键字按功能路径分组，并依据其在模型中的作用按逻辑顺序排列。这里采用的关键字顺序与附录 A“功能性关键字/参数参考”中的顺序一致。

每个关键字均给出：

- 语法；
- 关键字类型：必需或可选；
- 是否可重复使用。

除非另有说明，同一路径中各关键字的先后顺序通常没有特殊要求。不过，建议采用本章及附录 A 所列的顺序。若某个关键字在路径中的位置存在特殊要求，将在其语法和类型说明之后明确指出。

后续各节的语法说明采用以下约定：

- 语法中全部使用大写字母并在原文中加下划线的参数，为必须按所示形式输入的**次级关键字**；
- 其他参数使用能够表明含义的描述性名称，并以首字母大写形式表示；
- 很多参数名称与 AERMOD 程序代码中的变量名一致；
- 参数外的圆括号表示该参数为可选参数；
- 可选参数留空时采用的默认值，将在相应关键字的说明中给出。

---

## 3.2 CO 控制路径的输入与选项

CO（Control）路径包含对整个模型运行进行总体控制的关键字，包括扩散选项、平均时间选项、地形高度选项及其他控制功能。

CO 路径必须是输入控制文件中的第一个功能路径。
