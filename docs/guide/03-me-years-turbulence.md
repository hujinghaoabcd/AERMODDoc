# 3.5 ME 气象路径：年份与湍流处理

> 对应 EPA 2023 版 AERMOD 用户指南第 3.5 节完整中文译文。路径标识、关键字、参数名、文件名、单位和控制文件示例保留英文；法规应用应以 EPA 英文原文及当前模型版本为准。

<a id="me-3-5-8"></a>
## 3.5.8 指定需要处理的年份数量

`ME` 路径中的 `NUMYEARS` 关键字允许用户指定所处理气象数据的年份数量，用于为 `MAXDCONT` 选项分配数组存储空间。

如果省略可选的 `NUMYEARS`，模型默认假定处理 5 年数据。

语法如下：

```text
ME NUMYEARS NumYrs
```

**类型：** 可选，不可重复。

`NumYrs` 指定所处理气象数据的完整年份数量。

## 3.5.9 指定湍流处理选项

从 21112 版本开始，用户可以要求 AERMOD 在特定条件下，将廓线文件中原本非缺失的湍流参数 \(\sigma_\theta\) 或 \(\sigma_w\) 设置为缺失值。

这些选项用于便于在特定条件下使用包含湍流数据的气象资料。

例如，用户可能需要在 AERMOD 中同时使用：

- 具有现场湍流数据的城市气象站；
- `URBAN` 城市选项。

此时可以通过这些选项忽略特定的现场湍流数据，而不必重新运行 AERMET。相关说明见《AERMOD 实施指南》第 3.3 节（EPA，2023b）。

语法如下：

```text
ME TurbOpt
```

**类型：** 可选，不可重复。

其中，`TurbOpt` 可以取以下值：

| 选项 | 作用 |
|---|---|
| `NOTURB` | 对所有小时，将 \(\sigma_\theta\) 和 \(\sigma_w\) 设置为缺失 |
| `NOTURBST` | 仅在稳定小时，将 \(\sigma_\theta\) 和 \(\sigma_w\) 设置为缺失 |
| `NOTURBCO` | 仅在对流小时，将 \(\sigma_\theta\) 和 \(\sigma_w\) 设置为缺失 |
| `NOSA` | 对所有小时，将 \(\sigma_\theta\) 设置为缺失 |
| `NOSW` | 对所有小时，将 \(\sigma_w\) 设置为缺失 |
| `NOSAST` | 仅在稳定小时，将 \(\sigma_\theta\) 设置为缺失 |
| `NOSWST` | 仅在稳定小时，将 \(\sigma_w\) 设置为缺失 |
| `NOSACO` | 仅在对流小时，将 \(\sigma_\theta\) 设置为缺失 |
| `NOSWCO` | 仅在对流小时，将 \(\sigma_w\) 设置为缺失 |

稳定小时和对流小时根据 Monin-Obukhov 长度 \(L\) 判断：

- \(L > 0\)：稳定小时；
- \(L < 0\)：对流小时。

`NOTURB` 和 `NOTURBST` 可以与 `CO MODELOPT` 路径中的 `DFAULT` 关键字同时使用。

其余湍流选项不能与 `DFAULT` 同时使用。如果同时指定：

1. AERMOD 会警告用户该选项不能与 `DFAULT` 一起使用；
2. 模型不会将相应湍流参数设置为缺失；
3. 即 AERMOD 会忽略该湍流选项。

对于仅在稳定条件或仅在对流条件下重置湍流参数的选项，AERMOD 会把被重置参数对应的日期、小时和湍流参数写入 `ERRORFIL` 关键字指定的文件。
