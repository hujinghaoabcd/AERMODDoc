# 2.0 入门——简明教程

本章通过一个简单应用示例，简要说明如何建立 AERMOD 模型运行所需的输入文件，主要面向刚开始使用 AERMOD 的用户。示例展示模型中较常用选项的使用方法。有关 AERMOD 可用选项及其设置方法的完整说明，见第 3 章。

本章示例是 AERMOD 对单一点源的简单应用。该污染源为位于偏远农村地区一座小型设施中的假想烟囱。由于烟囱高度低于良好工程实践（Good Engineering Practice，GEP）烟囱高度，邻近建筑物产生的空气动力学下洗会影响其排放烟羽。

本教程依次说明：

- 模拟选项的选择与设置；
- 污染源参数的设置；
- 受体位置的定义；
- 输入气象资料的设置；
- 输出选项的选择。

由于本章主要面向初学者，首先概述 AERMOD 的输入和输出文件，以及控制文件采用的关键字/参数方式。
