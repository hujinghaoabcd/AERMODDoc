### 3.2.13 运行或仅检查输入

`RUNORNOT` 指定模型执行完整计算，还是只处理并检查控制文件。

```text
CO RUNORNOT RUN
CO RUNORNOT NOT
```

复杂项目建议先执行输入检查，再改为 `RUN`。

### 3.2.14 EVENT 输入文件

相关控制选项可生成供 EVENT 处理器使用的事件文件，用于调查设计值、阈值超限和污染源贡献。

### 3.2.15 模型重新启动

- `SAVEFILE`：周期性保存中间结果；
- `INITFILE`：从已保存文件恢复计算。

使用两个交替保存文件可降低程序中断时单一文件损坏的风险。

### 3.2.16—3.2.17 NAAQS 专门处理

AERMOD 提供针对以下标准统计形式的专门处理：

- PM₂.₅；
- PM₁₀；
- 1 小时 NO₂；
- 1 小时 SO₂。

应正确设置模拟年份、排序值、缺失数据和多年统计选项，并使用 OU 路径相应输出文件核查结果。

### 3.2.18 调试输出

调试关键字可输出烟羽、建筑物下洗、城市、NO₂ 转换和开发选项的中间变量。调试文件可能很大，只应在排查具体问题时启用。

### 3.2.19 详细错误消息文件

`ERRORFIL` 将全部模型消息写入指定文件：

```text
CO ERRORFIL errormsg.out
```

主输出只汇总致命错误和警告，而详细消息文件还包含信息消息及其生成顺序。消息字段和代码格式见附录 B。
