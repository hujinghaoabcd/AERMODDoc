# 3.3 SO 污染源路径的输入与选项

SO（Source）路径定义污染源位置、源类型、排放参数、沉降参数、NO₂ 转换参数、建筑物下洗、可变排放、污染源组及其他源级选项。

使用任何源级关键字前，必须先通过 `LOCATION` 定义源 ID 和源类型。`SRCGROUP` 通常应位于 `SO FINISHED` 之前的最后位置。
