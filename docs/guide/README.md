# AERMOD 用户指南中文在线版

本在线文档依据美国 EPA《User's Guide for the AMS/EPA Regulatory Model (AERMOD)》（EPA-454/B-23-008，2023 年 10 月）完整中文译稿整理。正文、控制文件语法、模型原始输出、参考文献和附录均已进入网站，并按在线查阅方式拆分为多个页面。

::: warning 法规应用说明
本译文用于阅读、研究和软件使用辅助。法规应用应以 EPA 英文原文、当前 AERMOD 版本说明以及主管机构要求为准。
:::
