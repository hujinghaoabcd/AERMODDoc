# AERMOD 用户指南中文译本

本在线文档依据美国环境保护署发布的 *User's Guide for the AMS/EPA Regulatory Model (AERMOD)* 翻译整理。

- **文号：** EPA-454/B-23-008
- **原版日期：** 2023 年 10 月
- **原版篇幅：** 330 页
- **中文内容：** 第 1—4 章及附录 A—E

::: warning 使用范围
本译文用于阅读、研究和软件使用辅助。涉及法规审查、许可申请或正式技术判定时，应以 EPA 发布的英文原文、现行《空气质量模型指南》以及主管机构要求为准。
:::
