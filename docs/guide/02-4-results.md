### 2.4.8 运行模型并检查结果

建立完整且无致命错误的控制文件后，即可运行 AERMOD 并检查结果。SCRAM 提供的 Windows 可执行程序支持以下三种命令形式：

```text
Path-to-AERMOD.EXE\AERMOD
Path-to-AERMOD.EXE\AERMOD runstream_input_filename
Path-to-AERMOD.EXE\AERMOD runstream_input_filename output_filename
```

第一种形式使用默认文件名：

```text
AERMOD.INP
AERMOD.OUT
```

后两种形式允许指定输入和输出文件。如果只给出输入文件，AERMOD 通常使用同一路径和基本文件名，并将扩展名替换为 `.OUT`。

运行前应确认：

- `AERMOD.EXE` 位于当前目录，或其目录已加入系统 `PATH`；
- 未在命令行指定输入文件时，`AERMOD.INP` 位于当前工作目录；
- 气象文件、外部包含文件及输出目录路径可访问；
- 控制文件中的 `RUNORNOT` 已设为 `RUN`。

模型首先处理设置数据，然后按儒略日显示计算进度。如果设置阶段存在致命错误，模型会停止扩散计算，并在屏幕和输出文件中报告消息。

## 主输出文件结构

AERMOD 主输出文件通常按以下顺序组织：

```text
输入控制文件命令回显
控制文件消息汇总
输入数据汇总
├─ 模拟选项
├─ 污染源数据
├─ 受体数据
└─ 气象数据
模型结果
├─ DAYTABLE 逐日结果（如选择）
├─ PERIOD 全时段结果（如选择）
├─ RECTABLE 按受体高值（如选择）
└─ MAXTABLE 总体最大值（如选择）
高值汇总表
完整模型运行消息汇总
```

除输入回显外，各页通常包含模型版本、AERMET 版本、用户标题、页码、运行日期和时间，以及本次运行的主要 `MODELOPT` 选项。

## 输入回显与复现

默认情况下，AERMOD 将控制文件逐行回显到主输出文件，以保留模型实际读取的输入和原始数值精度。由于输入处理在 `OU FINISHED` 处结束，完整输出文件在许多情况下也可以再次作为输入，用于复现该次运行。

当控制文件非常长时，可以使用：

```text
NO ECHO
```

关闭其后内容的回显。例如，可在 CO 路径之后加入 `NO ECHO`，保留模型选项但不重复打印大量污染源或受体记录。

## 检查结果的建议顺序

1. **消息汇总：** 是否存在致命错误、警告或重要信息消息；
2. **模型选项汇总：** `DFAULT`、地形、城市/农村、沉降和 NO₂ 转换等是否符合方案；
3. **污染源汇总：** 坐标、高程、排放率、烟囱参数和建筑物下洗参数是否正确；
4. **受体汇总：** 网络范围、间距、离散受体和旗杆高度是否完整；
5. **气象汇总：** 站点、年份、处理时段、静风与缺失小时是否合理；
6. **结果表：** 平均时间、污染源组、单位、最大值位置和发生日期是否符合预期；
7. **专用输出文件：** `POSTFILE`、`PLOTFILE`、`MAXIFILE` 等是否成功生成。

::: warning
程序显示 “AERMOD Finishes Successfully” 只说明运行完成，并不等同于输入、选项和结果必然适合具体法规应用。所有警告和关键设置仍应逐项审核。
:::

## 常见受体类型缩写

| 缩写 | 含义 |
|---|---|
| `GC` | 笛卡尔网格受体（GRIDCART） |
| `GP` | 极坐标网格受体（GRIDPOLR） |
| `DC` | 笛卡尔离散受体（DISCCART） |
| `DP` | 极坐标离散受体（DISCPOLR） |

输出路径各类表格和专用文件的详细设置见第 3.7 节，文件格式见附录 C。
