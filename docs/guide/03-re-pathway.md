# 3.4 RE 受体路径：概述与高程单位

> 对应 EPA 2023版用户指南第3章 RE路径完整译文（英文原文印刷页码3-128至3-140）。路径标识、关键字、参数名、源 ID、网络 ID 和控制文件语法保留英文；法规应用应以EPA英文原文及当前模型版本为准。

`RE`（REceptor，受体）路径包含用于定义特定模型运行中受体信息的关键字。

在 `RE` 路径中，用户可以定义：

- 笛卡尔网格受体网络；
- 极坐标网格受体网络；
- 等间距或非等间距网格；
- 采用笛卡尔坐标表示的离散受体；
- 采用极坐标表示的离散受体。

AERMOD 在运行时动态分配受体和受体网络所需的内存。受体数量与受体网络数量，以及其他动态分配数组和输入要求，原则上只受计算机可用内存限制。

AERMOD 的所有受体选项均允许用户为每个受体输入：

- 地形高程；
- 山丘高度尺度（hill height scale）。

在高地形条件下应用 AERMOD 时，这两个参数均为必要输入。

为便于生成 AERMOD 所需的山丘高度尺度，EPA 开发了地形预处理程序 AERMAP。AERMAP 可以处理美国地质调查局（USGS）的数字高程模型（DEM）数据和国家高程数据集（NED），也可以生成受体位置的地形高程。

AERMAP 输出文件按照本节所述格式生成 AERMOD 的 `RE` 路径数据。用户可以：

1. 将这些数据复制并粘贴到 AERMOD 控制文件中；
2. 使用 `RE INCLUDED` 语句将其作为外部文件引入，见第 3.4.4 节。

<a id="re-3-4-0"></a>
## 3.4.0 受体高程单位

AERMOD 中受体高程的默认单位为米。用户可以在 `RE STARTING` 之后立即加入以下语句，将受体高程单位指定为英尺：

```text
RE ELEVUNIT FEET
```

也可以明确指定为米：

```text
RE ELEVUNIT METERS
```

由于 AERMAP 输出的高程单位为米，并将 `RE ELEVUNIT METERS` 作为第一条记录，因此 AERMAP 生成的数据必须置于受体路径的开头。
