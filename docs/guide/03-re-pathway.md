# 3.4 RE 受体路径的输入与选项

RE（Receptor）路径定义模型计算位置，包括笛卡尔网格、极坐标网格和离散受体。

## 主要关键字

| 关键字 | 用途 |
|---|---|
| `GRIDCART` | 定义笛卡尔网格受体网络 |
| `GRIDPOLR` | 定义极坐标网格受体网络 |
| `DISCCART` | 定义笛卡尔离散受体 |
| `DISCPOLR` | 定义极坐标离散受体 |
| `EVALCART` | 定义用于模型评价的受体弧线或组 |
| `INCLUDED` | 从外部文件读入受体数据 |

网格关键字采用子路径结构，以 `STA` 开始、以 `END` 结束。每个网络具有最多 8 个字符的网络 ID。

## 笛卡尔网格

`GRIDCART` 可通过以下方式定义坐标：

- `XYINC`：起点、点数和固定增量；
- `XPNTS`、`YPNTS`：逐一列出坐标；
- `ELEV`：受体地形高程；
- `HILL`：山丘高度尺度；
- `FLAG`：旗杆高度。

## 极坐标网格

`GRIDPOLR` 的常用次级关键字包括：

- `ORIG`：指定原点坐标或源 ID；
- `DIST`：距离环；
- `GDIR`：按起始方向和间隔生成方向；
- `DDIR`：逐一指定方向；
- `ELEV`、`HILL`、`FLAG`：高程、山丘尺度和旗杆高度。

## 离散受体

`DISCCART` 和 `DISCPOLR` 适合道路附近、厂界、敏感点和网格补充位置。离散受体记录可包含：

- 平面坐标或极坐标；
- 地形高程；
- 山丘高度尺度；
- 旗杆高度；
- 可选受体标识。

高地形应用中的 `ZELEV` 和 `ZHILL` 通常由 AERMAP 计算。坐标系统、单位、基准和污染源位置必须保持一致。

RE 路径以：

```text
RE STARTING
...
RE FINISHED
```

包围全部受体输入。
