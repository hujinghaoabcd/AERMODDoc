# 3.6 EV 事件路径的输入与选项

> 对应 EPA 2023 版 AERMOD 用户指南第 3.6 节完整中文译文。路径标识、关键字、参数名、事件名、源组 ID、日期格式和控制文件示例保留英文；法规应用应以 EPA 英文原文及当前模型版本为准。

AERMOD 的 `EVENT` 处理专门用于分析短期平均时间（不超过 24 小时）特定事件的污染源贡献。事件可以是：

- AERMOD 计算得到的设计浓度；
- 超过空气质量标准或用户阈值的事件；
- 用户自行指定的事件。

这些事件通过 `EV`（Event，事件）路径输入。每个事件由以下内容共同定义：

1. 平均时间；
2. 具体数据时段；
3. 污染源组；
4. 受体位置。

由于受体位置只有与特定平均时间和数据时段组合时才有意义，因此进行 `EVENT` 处理时不使用 `RE` 受体路径。

在 `EV` 路径中，主要使用两个关键字定义事件：

- `EVENTPER`：定义平均时间、数据时段和污染源组；
- `EVENTLOC`：定义受体位置。

每个事件还必须指定一个字母数字形式的事件名称，用于把同一事件的两条输入记录关联起来。

## 3.6.0 `EVENTPER` 和 `EVENTLOC` 的语法

### `EVENTPER`

```text
EV EVENTPER Evname Aveper Grpid Date
```

### `EVENTLOC`：笛卡尔坐标形式

```text
EV EVENTLOC Evname XR= Xr YR= Yr (Zelev) (Zflag)
```

### `EVENTLOC`：极坐标形式

```text
EV EVENTLOC Evname RNG= Rng DIR= Dir (Zelev) (Zflag)
```

**类型：** 必需，可重复。

参数说明如下：

| 参数 | 说明 |
|---|---|
| `Evname` | 事件名称，最多 8 个字母或数字字符 |
| `Aveper` | 事件平均时间，例如 1、3、8 或 24 小时 |
| `Grpid` | 污染源组 ID；必须已在 `SO` 路径中定义 |
| `Date` | 事件数据时段结束时刻，以 8 位整数 `YYMMDDHH` 输入 |
| `XR=` | 表示后续参数为笛卡尔 x 坐标 |
| `Xr` | 事件位置的 x 坐标，单位 m |
| `YR=` | 表示后续参数为笛卡尔 y 坐标 |
| `Yr` | 事件位置的 y 坐标，单位 m |
| `RNG=` | 表示后续参数为极坐标距离 |
| `Rng` | 相对于极坐标原点 `(0, 0)` 的距离，单位 m |
| `DIR=` | 表示后续参数为极坐标方向角 |
| `Dir` | 相对于原点 `(0, 0)` 的方向角，单位度 |
| `Zelev` | 可选的事件位置地形高程，单位 m |
| `Zflag` | 可选的离地受体高度，即旗杆高度，单位 m |

### 日期格式

`Date` 表示事件数据时段的**结束小时**。例如：

```text
84030324
```

表示 1984 年 3 月 3 日第 24 小时结束。事件实际覆盖的时间长度由 `Aveper` 决定：

- `Aveper = 1`：以该时刻结束的 1 小时平均；
- `Aveper = 24`：以该时刻结束的 24 小时平均。

### 事件名称和记录关联

每个事件必须同时具有一条 `EVENTPER` 和一条 `EVENTLOC` 记录，两条记录通过 `Evname` 关联。

在同一次运行中：

- 每个 `Evname` 必须唯一；
- `EV` 路径记录没有严格的排列顺序要求；
- 只要两条记录使用相同的 `Evname`，模型即可建立关联。

事件位置可以采用笛卡尔坐标或极坐标，但极坐标必须相对于固定原点 `(0, 0)`。
