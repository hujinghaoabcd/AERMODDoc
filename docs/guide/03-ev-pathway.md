# 3.6 EV 事件路径的输入与选项

EV（Event）路径用于对特定日期、时段和受体位置进行事件处理，主要用于源贡献或污染源归因分析。

EVENT 处理通常分两步：

1. 常规 AERMOD 运行识别设计值、阈值超限或其他关注事件，并生成事件输入信息；
2. EVENT 运行针对这些事件计算单个污染源或污染源组贡献。

## 主要输入

事件记录通常需要：

- 事件 ID；
- 污染源组；
- 平均时间；
- 事件结束日期和小时；
- 受体坐标、高程和旗杆高度；
- 需要输出的污染源贡献信息。

```text
EV STARTING
...
EV FINISHED
```

EVENT 处理适用于调查特定高值的来源，不应把独立污染源在不同时空位置的最大值直接相加。事件日期、受体位置和源贡献必须在时间与空间上配对。

PM₂.₅、NO₂ 和 SO₂ NAAQS 的专门源贡献输出通常优先使用 `MAXDCONT` 等相应选项。
