# 3.4 RE 受体路径：外部受体文件

> 对应 EPA 2023版用户指南第3章 RE路径完整译文（英文原文印刷页码3-128至3-140）。路径标识、关键字、参数名、源 ID、网络 ID 和控制文件语法保留英文；法规应用应以EPA英文原文及当前模型版本为准。

<a id="re-3-4-4"></a>
## 3.4.4 从外部文件引入受体数据

用户可以使用 `RE` 路径中的 `INCLUDED` 关键字，从外部文件引入受体数据。

`RE INCLUDED` 可以置于 `RE STARTING` 之后、`RE FINISHED` 之前。外部文件本身不能包含：

```text
RE STARTING
RE FINISHED
```

外部文件中的内容会像主控制文件的一部分一样处理。

```text
RE INCLUDED Incfil
```

**类型：**可选，可重复。

`Incfil` 为最多 40 个字符的外部文件名。文件内容必须是有效的 `RE` 路径控制语句。

处理外部文件时发生错误，错误消息会报告该文件中的行号。使用多个 `INCLUDED` 文件时，还需结合输入顺序判断错误来自哪个文件。

如果主控制文件的起始列相对于第 1 列发生偏移，外部文件中的控制语句也必须使用相同列偏移。

`INCLUDED` 可以直接引入 AERMAP 生成的受体数据，无需复制粘贴。由于 AERMAP：

- 以米为单位生成地形高程；
- 将 `RE ELEVUNIT METERS` 作为输出文件第一条记录；

因此，AERMAP 文件必须在 `RE` 路径开始处引入，即紧接 `RE STARTING`。同一 `RE` 路径引入多个 AERMAP 输出文件时，除第一个文件外，应删除其余文件中的 `RE ELEVUNIT METERS`。

---

## RE 路径结束记录

完成受体定义后，应使用：

```text
RE FINISHED
```
