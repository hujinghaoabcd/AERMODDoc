# 3.5 ME 气象路径：风向、风速与 SCIM

> 对应 EPA 2023 版 AERMOD 用户指南第 3.5 节完整中文译文。路径标识、关键字、参数名、文件名、单位和控制文件示例保留英文；法规应用应以 EPA 英文原文及当前模型版本为准。

<a id="me-3-5-5"></a>
## 3.5.5 修正风向对准问题

`WDROTATE` 关键字允许用户修正输入气象数据中的风向对准问题。模型会按照用户指定的角度旋转所有输入风向或流动矢量。

由于特定受体位置处的模型结果通常对输送风向非常敏感，因此只有在具有明确依据和充分说明时，才应非常谨慎地使用该可选关键字。

语法如下：

```text
ME WDROTATE Rotang
```

**类型：** 可选，不可重复。

`Rotang` 指定输入风向测量值需要旋转的角度，单位为度。

模型从风向测量值中减去 `Rotang`：

\[
WD_{\mathrm{adjusted}} = WD_{\mathrm{input}} - Rotang
\]

该选项可用于：

- 修正已知且有记录的仪器校准误差；
- 当气象站位于一个山谷中，而污染源位置处山谷走向不同，对山谷方向差异进行调整。

## 3.5.6 指定风速类别

模型可以输入随风速类别变化的可变排放速率系数。

AERMOD 使用 6 个风速类别。用户通过指定前 5 个类别的风速上限来定义类别边界，第 6 个类别被认为没有上限。

默认风速类别上限依次为：

```text
1.54, 3.09, 5.14, 8.23, 10.8 m/s
```

用户可以使用 `WINDCATS` 关键字指定不同的类别边界。

语法如下：

```text
ME WINDCATS Ws1 Ws2 Ws3 Ws4 Ws5
```

**类型：** 可选，不可重复。

其中，`Ws1` 至 `Ws5` 分别表示第 1 至第 5 个风速类别的上限，单位为 m/s。

类别上限为包含边界值。例如，风速等于 `Ws1` 时，会被归入第 1 个风速类别。

## 3.5.7 指定 SCIM 参数

`SCIMBYHR` 语句中的 SCIM 参数用于指定：

- 常规抽样的起始小时；
- 常规抽样间隔；
- 湿时段抽样的起始小时；
- 湿时段抽样间隔；
- 可选的输出文件名。

语法如下：

```text
ME SCIMBYHR NRegStart NRegInt NWetStart NWetInt (SfcFilnam PflFilnam)
```

**类型：** 可选，不可重复。

参数说明如下：

| 参数 | 说明 |
|---|---|
| `NRegStart` | 常规抽样的第一个抽样小时 |
| `NRegInt` | 常规抽样间隔 |
| `NWetStart` | 第一个湿小时，即降水量不为零的小时 |
| `NWetInt` | 湿时段抽样间隔 |
| `SfcFilnam` | 可选的抽样地表气象数据输出文件名 |
| `PflFilnam` | 可选的抽样廓线气象数据输出文件名 |

原文第 3.5.7 节说明：由于该处所述 SCIM 湿时段抽样功能未投入运行，用户应将 `NWetStart` 和 `NWetInt` 均设为 `0`。

> **原文一致性说明：** 同版指南第 3.2.2.12 节同时说明 AERMOD 包含干、湿沉降算法。因此，这里应理解为 **SCIM 的湿时段抽样选项不可操作**，而不是 AERMOD 整体不具备湿沉降计算功能。

如果指定 `SfcFilnam` 和 `PflFilnam`，模型会创建包含抽样小时地表和廓线气象数据的输出文件。这些文件采用与主输出文件中前 24 小时气象数据汇总相同的格式。

要使用 SCIM，必须在 `CO MODELOPT` 语句中指定非 `DFAULT` 的 `SCIM` 选项。

尽管 `ME SCIMBYHR` 在语法上属于可选语句，但使用 SCIM 选项时必须输入该语句。

`NRegStart` 的取值必须为 1—24，即第一个抽样小时必须位于气象数据文件的第一天。

`NRegInt` 没有强制限制，但通常应大于 1。例如，可以根据下式确定：

\[
NRegInt = 24n + 1
\]

其中，\(n\) 为两次样本之间跳过的天数。

采用该形式可以确保抽样小时形成规则的日变化循环。例如：

- `25`：每隔 1 天抽取一次，并使抽样小时顺次变化；
- `49`：每隔 2 天抽取一次。
