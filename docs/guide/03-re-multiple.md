# 3.4 RE 受体路径：多个受体网络

> 对应 EPA 2023版用户指南第3章 RE路径完整译文（英文原文印刷页码3-128至3-140）。路径标识、关键字、参数名、源 ID、网络 ID 和控制文件语法保留英文；法规应用应以EPA英文原文及当前模型版本为准。

<a id="re-3-4-2"></a>
## 3.4.2 使用多个受体网络

某些模拟应用可能需要：

- 使用间距较大的粗网格覆盖较大区域，以识别厂区显著影响的大致范围；
- 同时使用更密集的局部网格覆盖较小区域，以确定最大影响位置。

为满足这一需求，AERMOD 允许在一次模型运行中指定多个受体网络。用户可以同时定义：

- 多个笛卡尔网格；
- 多个极坐标网格；
- 笛卡尔网格与极坐标网格的组合。

通过 `GRIDPOLR` 的 `ORIG` 选项，用户可以：

- 将一个极坐标网络以拟许可设施为中心；
- 将另一个网络以已知会显著贡献高浓度的背景污染源为中心；
- 将极坐标网络以某一需要重点保护的受体位置为中心，例如附近的 Class I 区域。

AERMOD 根据受体数量和受体网络数量，在运行时动态分配数组存储空间，其上限取决于计算机可用内存。
