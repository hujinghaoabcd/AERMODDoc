## 3.3.2 指定污染源排放参数

`SRCPARAM` 的参数形式取决于 `LOCATION` 中定义的源类型。输入不匹配时，AERMOD 会在设置阶段报告错误。

| 源类型 | 典型参数 |
|---|---|
| `POINT`、`POINTHOR`、`POINTCAP` | 排放率、烟囱高度、出口温度、出口速度、直径 |
| `VOLUME` | 排放率、释放高度、初始横向和垂向尺度 |
| `AREA` | 排放率/面积、释放高度、边长、旋转角、初始垂向尺度 |
| `AREAPOLY` | 排放率/面积、释放高度、顶点数、初始垂向尺度；顶点另行输入 |
| `AREACIRC` | 排放率/面积、释放高度、半径、顶点数、初始垂向尺度 |
| `OPENPIT` | 排放率/面积、释放高度、体积、有效深度和顶点 |
| `LINE` | 排放率/长度、释放高度、宽度、初始垂向尺度 |
| `RLINE`、`RLINEXT` | 排放率/长度、释放高度、道路宽度及扩展道路参数 |
| `BUOYLINE` | 线源排放及 BLP 组参数 |
| `SWPOINT` | 研究级侧洗源参数 |

体积源和线源的初始扩散尺度应依据源几何、相邻源间距或建筑物尺寸确定。`RLINE/RLINEXT` 可结合 `RBARRIER` 表示道路声屏障，使用 `RDEPRESS` 表示下沉道路。

::: tip
道路源排放单位、道路宽度、端点方向以及逐小时排放文件的单位转换必须成套核对，避免把“每条线总排放率”和“单位长度排放率”混用。
:::
