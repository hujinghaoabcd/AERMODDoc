# 3.3 SO 污染源路径：沉降与单位

> 对应 EPA 2023版用户指南第3章 SO路径完整译文（英文原文印刷页码3-61至3-127）。路径标识、关键字、次级关键字、参数名、源类型、文件名和控制文件语法保留英文；法规应用应以EPA英文原文及当前模型版本为准。

<a id="so-3-3-3"></a>
## 3.3.3 指定气态污染物沉降参数

### 3.3.3.1 气态污染物干沉降和/或湿沉降的源参数

气态污染物干、湿沉降所需的污染源参数通过 SO 路径的 `GASDEPOS` 控制。参数既可针对单个污染源输入，也可应用于一个源范围。

**语法：**

```text
SO GASDEPOS Srcid (or Srcrng) Da Dw rcl Henry
```

**类型：**可选，可重复。  
**顺序：**必须位于相应源的 `LOCATION` 之后。

参数含义：

- `Srcid` 或 `Srcrng`：参数适用的单个源或源范围；
- `Da`：所模拟污染物在空气中的扩散系数，单位 cm²/s；
- `Dw`：所模拟污染物在水中的扩散系数，单位 cm²/s；
- `rcl`：单片叶片脂质层吸收的角质层阻力，单位 s/cm；
- `Henry`：亨利定律常数，单位 Pa·m³/mol。

若干常见污染物的物理参数值见 Argonne National Laboratory 报告附录（Wesely 等，2002）。

从 21112 版本开始，AERMOD 为元素汞、二价汞、二噁英、多环芳烃（PAH）、SO₂ 和 NO₂ 提供可选的默认气体沉降参数。使用默认值必须同时满足：

1. `POLLUTID` 使用下表规定的污染物标识；
2. 希望采用默认值的参数在 `GASDEPOS` 中输入 `0`。

若四个参数均采用默认值，应依次输入四个 `0`。也可以混合使用用户输入值和默认值，例如为 `Da` 输入实测值，而为 `Dw` 输入 `0` 以采用默认值。某个源使用任何默认沉降参数时，模型会在 `ERRORFIL` 中记录消息。

#### 默认气体沉降参数

| 污染物 | `POLLUTID` | 空气扩散系数 `Da` (cm²/s) | 水中扩散系数 `Dw` (cm²/s) | 角质层阻力 `rcl` (s/cm) | 亨利常数 `Henry` (Pa·m³/mol) |
|---|---:|---:|---:|---:|---:|
| 元素汞 | `HG0` | 0.055 | 6.4E-6 | 100000 | 719 |
| 二价汞 | `HGII` | 0.045 | 5.2E-6 | 100000 | 0.000072 |
| 二噁英，以 TCDD 表示 | `TCDD` | 0.05196 | 4.39E-6 | 9.67 | 1.46 |
| PAH，以 BaP 表示 | `BAP` | 0.0513 | 4.44E-6 | 0.441 | 0.046 |
| SO₂ | `SO2` | 0.1122 | 1.83E-5 | 732 | 72 |
| NO₂ | `NO2` | 0.1361 | 1.4E-5 | 12000 | 8444 |

注意：元素汞的 `POLLUTID` 为 `HG0`，第三个字符是数字零；`SO2` 和 `NO2` 中的第三个字符是大写字母 `O`，不是零。

### 3.3.3.2 直接指定气体干沉降速度

CO 路径提供可选关键字 `GASDEPVD`，允许用户直接指定气态排放的干沉降速度。一次模型运行只能输入一个沉降速度，并应用于全部气态污染源。

该选项会绕过 AERMOD 用于计算气体沉降速度的算法，因此只应在运行完整算法所需的数据不足时使用。基于用户直接指定沉降速度的结果，应格外谨慎解释。

**语法：**

```text
CO GASDEPVD Uservd
```

**类型：**可选，不可重复。

其中 `Uservd` 为气体干沉降速度，单位 m/s。用户输入值大于 0.05 m/s，即 5 cm/s 时，模型给出非致命警告。

使用 `GASDEPVD` 后，以下关键字不再适用，并且不能在同一次运行中使用：

- CO 路径：`GDSEASON`、`GDLANUSE`、`GASDEPRF`；
- SO 路径：`GASDEPOS`。

同时，使用 `GASDEPVD` 时不能模拟气体湿沉降过程，因此不能配合 `DEPOS`、`WDEP` 或 `WETDPLT`。

## 3.3.4 指定颗粒物沉降的源参数

AERMOD 提供两种方法处理颗粒物干沉降和/或湿沉降。

### 方法 1 的适用条件

当以下任一条件满足时，应使用方法 1：

- 总颗粒物质量中，粒径不小于 10 μm 的比例较大，约超过 10%；
- 已较可靠地掌握颗粒物粒径分布。

方法 1 要求对粒径分布有较好的认识。

### 方法 2 的适用条件

当粒径分布不清楚，且粒径不小于 10 μm 的颗粒只占较小质量比例，约低于 10% 时，可使用方法 2。

方法 2 的沉降速度，是以下两类颗粒沉降速度的质量加权平均：

- 细模态：粒径小于 2.5 μm；
- 粗模态：粒径大于 2.5 μm、但小于 10 μm。

方法 2 属于非 `DFAULT` 选项，指定 `DFAULT` 时不能使用。

### 3.3.4.1 方法 1 的颗粒物输入

方法 1 通过 SO 路径的三个关键字输入：

- `PARTDIAM`；
- `MASSFRAX`；
- `PARTDENS`。

这些输入与 ISCST3 使用的颗粒物参数相似。参数可以用于单个源或源范围。

**语法：**

```text
SO PARTDIAM Srcid (or Srcrng) Pdiam(i), i=1,Npd
SO MASSFRAX Srcid (or Srcrng) Phi(i),   i=1,Npd
SO PARTDENS Srcid (or Srcrng) Pdens(i), i=1,Npd
```

**类型：**可选，可重复。  
**顺序：**必须位于相应源的 `LOCATION` 之后。

参数含义：

- `Pdiam(i)`：第 i 个粒径类别的质量平均空气动力学直径，单位 μm；
- `Phi(i)`：第 i 个粒径类别的质量分数，取值 0 至 1；
- `Pdens(i)`：第 i 个粒径类别的颗粒密度，单位 g/cm³；
- `Npd`：该污染源的粒径类别数。

用户不需要单独输入 `Npd`。模型根据参数数量识别类别数。若一个关键字需要多条续行记录，则同一源或源范围的这些记录必须连续出现。对同一源，三个关键字中的粒径类别数量必须一致。

可使用任意数量的续行记录。模型检查：

- 各粒径类别质量分数之和是否在 1.0 的 ±2% 范围内；超出时给出警告；
- 每个 `Phi(i)` 是否位于 0 至 1；超出时给出致命错误。

### 3.3.4.2 方法 2 的颗粒物输入

方法 2 通过 SO 路径的 `METHOD_2` 输入。

**语法：**

```text
SO METHOD_2 Srcid (or Srcrng) FineMassFraction Dmm
```

**类型：**可选，可重复。  
**顺序：**必须位于相应源的 `LOCATION` 之后。

参数含义：

- `Srcid` 或 `Srcrng`：适用的源或源范围；
- `FineMassFraction`：细模态颗粒质量分数，粒径小于 2.5 μm，取值 0 至 1；
- `Dmm`：代表性质量平均空气动力学粒径，单位 μm。

不同污染物的细颗粒比例和质量平均粒径估计值，见 Wesely 等（2002）报告附录 B。

从 21112 版本开始，AERMOD 为砷、镉、铅、汞和多环芳烃提供可选的默认方法 2 参数。使用默认值需满足：

1. `POLLUTID` 使用下表规定值；
2. 希望采用默认值的参数在 `METHOD_2` 中输入 `0`。

两个参数均采用默认值时，应输入两个 `0`。也可混合使用，例如用户输入细颗粒质量分数，而对 `Dmm` 输入 `0`。使用任何默认值时，模型在 `ERRORFIL` 中记录消息。

#### 默认方法 2 颗粒物沉降参数

| 污染物 | `POLLUTID` | 细颗粒质量分数 `FineMassFraction` | 平均粒径 `Dmm` (μm) |
|---|---:|---:|---:|
| 砷 | `AS` | 0.75 | 0.5 |
| 镉 | `CD` | 0.70 | 0.6 |
| 铅 | `PB` | 0.75 | 0.5 |
| 汞 | `HG` | 0.80 | 0.4 |
| PAH，以颗粒有机碳表示 | `POC` | 0.90 | 0.1 |

## 3.3.5 指定排放与输出单位

AERMOD 可以在同一次运行中输出浓度和沉降。当一次运行生成多个输出类型时，不能使用 `EMISUNIT` 同时定义统一的排放单位换算。为此，模型允许分别通过 `CONCUNIT` 和 `DEPOUNIT` 设置浓度与沉降单位。

### CONCUNIT

**语法：**

```text
SO CONCUNIT Emifac Emilbl Conlbl
```

**类型：**可选，不可重复。

参数含义：

- `Emifac`：将排放输入单位换算为目标浓度输出单位的因子；
- `Emilbl`：排放输入单位标签，最长 40 个字符；
- `Conlbl`：浓度输出单位标签，最长 40 个字符。

默认换算为 g/s 到 μg/m³，`Emifac = 1×10^6`。例如：

- g/s 到 mg/m³：`1×10^3`；
- g/s 到 ppb：使用该污染物由 g/m³ 转为 ppb 的换算因子。

### DEPOUNIT

**语法：**

```text
SO DEPOUNIT Emifac Emilbl Deplbl
```

**类型：**可选，不可重复。

参数含义：

- `Emifac`：排放输入单位到目标沉降输出单位的换算因子；
- `Emilbl`：排放输入单位标签，最长 40 个字符；
- `Deplbl`：沉降输出单位标签，最长 40 个字符。

默认换算为 g/s 到 g/m²，换算因子为 `3600`。若输出 ng/m²，则换算因子为：

```text
3.6×10^12 = 3600 × 1×10^9
```

其中 `1×10^9` 是克到纳克的换算因子。
