# C.5 TOXX 模型输入文件（TOXXFILE 选项）

`OU TOXXFILE` 允许用户针对特定平均时间生成一个或多个未格式化阈值超标文件，供 TOXST 的 TOXX 模型组件使用。

## C.5.1 文件头记录

文件包括三个文件头记录：

| 记录 | 内容 |
|---:|---|
| 1 | 标题，80 个字符 |
| 2 | `IYEAR, NUMGRP, NUMREC, NUMPER, ITAB, NXTOX, NYTOX, IDUM1, IDUM2, IDUM3` |
| 3 | `CUTOFF, RDUM1, ..., RDUM9` |

变量说明：

| 变量 | 含义 |
|---|---|
| `TITLE` | 第一行标题，80 个字符 |
| `IYEAR` | 模拟年份 |
| `NUMGRP` | 污染源组数量 |
| `NUMREC` | 受体总数 |
| `NUMPER` | 平均时段数量，例如一年中的小时数 |
| `ITAB` | 受体网络类型 |
| `NXTOX` | 受体网络中的 x 坐标数或距离数 |
| `NYTOX` | 受体网络中的 y 坐标数或方向数 |
| `IDUM1`—`IDUM3` | 虚拟整数变量，任意设为 0 |
| `CUTOFF` | 用户指定的结果输出阈值，g/m³ |
| `RDUM1`—`RDUM9` | 9 个虚拟实数变量，任意设为 0 |

`ITAB` 取值：

| 值 | 受体类型 |
|---:|---|
| `1` | 极坐标网格 |
| `2` | 笛卡尔网格 |
| `0` | 离散受体或混合网格 |

## C.5.2 数据记录与标识变量

文件头之后为成对记录：

1. 标识平均时段、污染源组编号和受体编号的 ID；
2. 相应浓度值。

如果任一污染源组在某一平均时段和受体位置超过阈值，则模型会输出该时段、该受体位置上**所有污染源组**的浓度。

每条记录包含的数值数量由 `NPAIR PARAMETER` 控制；其初始值在 `MODULE MAIN1` 中设为 100。

标识变量计算公式为：

\[
IDCONC = IPER \times 100000 + IGRP \times 1000 + IREC
\]

其中：

| 变量 | 含义 |
|---|---|
| `IPER` | 浓度值对应的年内小时序号 |
| `IGRP` | 污染源组编号，即该组在 `SO` 路径中的定义顺序 |
| `IREC` | 受体编号，即受体在 `RE` 路径中的定义顺序 |
