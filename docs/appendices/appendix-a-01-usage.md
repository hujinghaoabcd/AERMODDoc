# A.1 使用说明

AERMOD 控制文件按以下功能路径组织，顺序不可颠倒：

| 路径 | 功能 |
|---|---|
| `CO` | 总体任务控制选项 |
| `SO` | 污染源信息 |
| `RE` | 受体信息 |
| `ME` | 气象信息与选项 |
| `EV` | 事件信息与选项 |
| `OU` | 输出选项 |

每条路径均提供两类参考表：

1. 关键字、类型和功能；
2. 关键字语法、参数顺序及参数含义。

类型符号：

| 符号 | 含义 |
|---|---|
| `M` | 必需 |
| `O` | 可选 |
| `N` | 不可重复 |
| `R` | 可重复 |

全部大写的参数通常是需要按原样输入的二级关键字。首字母大写、其余小写的名称用于表示用户填写的变量。圆括号表示该参数可选。
