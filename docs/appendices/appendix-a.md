# 附录 A　功能性关键字/参数参考

> 对应英文原文印刷页码 A-1 至 A-45。  
> 本附录是第3章的快速参考。关键字、二级关键字、参数名、文件名和代码语法保留英文；功能说明译为中文。

本附录保留原文 **12张参考表**，并按六条功能路径拆分为8个在线页面。推荐采用以下查阅顺序：

1. 在本附录确认关键字类型、参数次序和简要含义；
2. 进入第3章查看适用条件、默认值、限制关系、法规状态和完整示例；
3. 正式模拟前，再核对当前模型版本的运行消息和EPA英文原文。
