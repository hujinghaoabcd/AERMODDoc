# 附录 E　术语表

| 英文术语 | 中文名称与说明 |
|---|---|
| AERMAP | AERMOD 地形预处理程序 |
| AERMET | AERMOD 气象预处理程序 |
| AERMOD | AMS/EPA 法规空气扩散模型 |
| ASCII | 美国信息交换标准代码；也常指纯文本文件 |
| Card / Input Image | 控制文件中的一条输入记录 |
| CO Pathway | 控制路径，指定总体运行选项 |
| Control File | 输入控制文件，组织模型选项和数据 |
| Dispersion Model | 模拟平均风输送和湍流扩散的数学算法集合 |
| Echo of Inputs | 将控制文件原样复制到主输出 |
| EOF | 文件结束 |
| Error Message | 会妨碍处理的错误消息 |
| EV Pathway | 事件路径 |
| EVENT Processing | 特定事件的源贡献/归因处理 |
| Fatal Error | 阻止有效后续处理的错误 |
| Flow Vector | 风吹向的方向，与气象风向来向相反 |
| Informational Message | 不影响结果有效性的信息消息 |
| Julian Day | 年内日序，1 月 1 日为 1 |
| Keyword | 路径 ID 后的 8 字符命令代码 |
| LST | 地方标准时间 |
| ME Pathway | 气象路径 |
| Missing Value | 表示时间或空间记录中断的缺失标志 |
| Mixing Height | 污染物通常能够发生垂向混合的深度 |
| NAAQS | 美国国家环境空气质量标准 |
| NWS | 美国国家气象局 |
| On-site Data | 模拟场址附近观测计划采集的气象数据 |
| OU Pathway | 输出路径 |
| Pasquill Stability Categories | Pasquill 大气稳定度类别 |
| Pathway | CO、SO、RE、ME、EV、OU 六个功能分区之一 |
| Quality Assessment | 数据质量评价 |
| Range Check | 检查变量是否处于预定义范围 |
| RE Pathway | 受体路径 |
| Regulatory Application | 按《空气质量模型指南》用于法规决策的模拟 |
| Regulatory Model | 获 EPA 批准用于法规工作的扩散模型 |
| R-LINE | 近地面线源研究扩散模型 |
| SCRAM | 法规空气模型支持中心 |
| SO Pathway | 污染源路径 |
| Surface Roughness Length | 近地面风速廓线外推至零风速的高度 |
| Syntax | 路径、关键字和参数的排列规则 |
| Unformatted File | 未使用 Fortran `FORMAT` 的二进制记录文件 |
| Upper Air Data / Soundings | 气球探空获得的气压、温度、湿度和风资料 |
| Vertical Potential Temperature Gradient | 位温随高度的变化率 |
| Warning Message | 不阻止处理但提示可疑条件的消息 |
