# 附录 E　术语表

> 对应原文印刷页码 E-7 至 E-12。  
> 为便于与 AERMOD 英文手册、控制文件及程序输出相互对照，术语英文名称予以保留，并给出中文含义和定义。

## A

### AERMAP — AERMOD 地形预处理程序

**英文全称：** AMS/EPA Regulatory Model (AERMOD) Terrain Preprocessor

用于为 AERMOD 处理地形和受体高程数据的预处理程序。

### AERMET — AERMOD 气象预处理程序

**英文全称：** AMS/EPA Regulatory Model (AERMOD) Meteorological Preprocessor

用于为 AERMOD 处理气象数据的预处理程序。

### AERMOD — AMS/EPA 法规模式

**英文全称：** AMS/EPA Regulatory Model

美国气象学会/美国环境保护署法规空气扩散模型。

### ASCII — 美国信息交换标准代码

**英文全称：** American Standard Code for Information Interchange

计算机和通信设备使用的一套标准代码。有时也用于指仅包含这些标准代码的文件，不包含文字处理程序文档中可能存在的应用程序专用代码。

---

## C

### Card — 卡片/输入记录

输入控制文件中的一条输入记录。

### CO — 控制路径标识

**英文：** COntrol

用于指定总体任务控制选项的输入控制文件命令所采用的两字符路径 ID。

### CO Pathway — CO 控制路径

用于指定总体任务控制选项的一组输入控制文件命令的统称，包括：

- 标题；
- 扩散选项；
- 地形选项；
- 其他控制选项。

### Control File — 控制文件

处理 AERMOD 输入选项和输入数据所需的全部输入记录的集合。

控制文件包括按照功能路径组织的输入记录，用于控制：

- 模拟选项；
- 污染源数据；
- 受体位置；
- 气象数据文件；
- 输出选项。

> 原文在术语表中同时使用了 `Input control file` 和 `Control file`。二者在本指南中通常均译为“输入控制文件”或“控制文件”。

---

## D

### Directory — 目录

磁盘上的逻辑分区，用于组织存储在磁盘中的文件。

### Dispersion Model — 扩散模型

一组相互关联的数学算法，用于估算或模拟污染物在大气中的扩散过程。

该扩散过程由以下因素造成：

- 平均风输送；
- 小尺度湍流。

### DOS — 磁盘操作系统

**英文全称：** Disk Operating System

用于管理应用软件，并在应用程序与磁盘驱动器、终端和键盘等系统硬件组件之间提供接口的软件。

---

## E

### Echo of Inputs — 输入回显

默认情况下，AERMOD 会将输入控制文件中的命令逐字符复制到主打印输出文件中。

输入回显可以：

- 保存用户最初输入内容的记录；
- 避免数值在输出时因舍入而发生变化。

可以使用 `NO ECHO` 选项关闭输入回显。

### EOF — 文件结束

**英文全称：** End-of-File

表示文件内容结束的标志。

### EPA — 美国环境保护署

**英文全称：** U.S. Environmental Protection Agency

### Error Message — 错误消息

当模型遇到会妨碍数据处理的错误时，写入错误/消息文件中的消息。

### Error/Message File — 错误/消息文件

用于保存模型所写消息的文件。

### EV — 事件路径标识

**英文：** EVent

用于指定短期 `EVENT` 处理事件输入的输入控制文件命令所采用的两字符路径 ID。

### EV Pathway — EV 事件路径

用于指定短期 `EVENT` 处理的事件时段和事件位置的一组输入控制文件命令的统称。

### EVENT Processing — EVENT 事件处理

AERMOD 中专门用于为特定关注事件提供污染源贡献或污染源归因信息的选项。

关注事件可以包括：

- 设计值；
- 阈值超标事件。

### Extended Memory — 扩展内存

80386 和 80486 个人计算机中超过 DOS 640 KB 内存限制的附加内存。

使用该部分内存需要专门软件。

---

## F

### Fatal Error — 致命错误

会阻止模型继续处理数据的错误。

发生致命错误时：

- 在设置阶段，模型仍会继续读取输入记录，以检查其他错误；
- 在计算阶段，模型仍可能继续读取输入气象数据。

### Flow Vector — 流动矢量

风吹向的方向。

> 风向观测通常表示风的来向，而流动矢量表示风的去向。

---

## G

### GMT — 格林尼治标准时间

**英文全称：** Greenwich Mean Time

本初子午线，即 0° 经线处的时间。

---

## I

### Informational Message — 信息消息

写入错误/消息文件中的消息。

该类消息：

- 可能对用户有参考价值；
- 不直接影响结果有效性；
- 不影响模型处理过程。

### Input Image — 输入记录映像

用户通过默认输入设备提供、用于控制模型选项和数据输入的内容。

一条输入记录映像相当于控制文件中的一张卡片或一条记录，包括：

1. 路径 ID，可以为空；为空时表示延续前一个路径；
2. 关键字，也可以为空；为空时表示延续前一个关键字；
3. 一个或多个参数字段。

### Input Control File — 输入控制文件

AERMOD 的基本输入文件，用于控制：

- 模拟选项；
- 污染源数据；
- 受体位置；
- 气象数据文件设置；
- 输出选项。

输入控制文件由按照不同功能路径分组的一系列输入记录组成。

---

## J

### Julian Day — 儒略日/年内日序

一年中的日期序号。

例如：

- 1 月 1 日为第 1 日；
- 12 月 31 日为第 365 日；
- 闰年的 12 月 31 日为第 366 日。

> 本指南中的 `Julian Day` 指年内日序，并非天文学中的连续儒略日编号。

---

## K

### KB — 千字节

**英文全称：** Kilobyte

磁盘存储单位，本指南定义为 1000 字节。

### Keyword — 关键字

输入运行数据中紧跟路径 ID 之后的 8 字符代码。

## L

### LST — 地方标准时间

**英文全称：** Local Standard Time

---

## M

### Math Co-processor — 数学协处理器

用于提高个人计算机浮点运算速度的计算机芯片。

### MB — 兆字节

**英文全称：** Megabyte

磁盘存储单位，本指南定义为 100 万字节。

### ME — 气象路径标识

**英文：** MEteorology

用于指定气象数据选项的输入控制文件命令所采用的两字符路径 ID。

### ME Pathway — ME 气象路径

用于指定以下内容的一组输入控制文件命令的统称：

- 输入气象数据文件；
- 其他气象变量；
- AERMOD 从气象文件中处理的时间范围。

### Meteorological Data File — 气象数据文件

包含气象数据的任何文件，例如：

- 混合层高度数据；
- 地表气象观测；
- 现场气象数据。

### Missing Value — 缺失值

用于表示某一大气变量的时间记录或空间记录存在中断的字母数字字符。

### Mixing Height — 混合层高度

大气污染物通常通过扩散过程发生混合的垂向深度。

## N

### NCDC — 美国国家气候数据中心

**英文全称：** National Climatic Data Center

负责分发美国国家气象局以下数据的联邦机构：

- 高空气象数据；
- 混合层高度数据；
- 地表观测数据。

### NO ECHO — 不回显输入

用于禁止将控制文件命令复制到主打印输出文件中的选项。

### NWS — 美国国家气象局

**英文全称：** National Weather Service

## O

### On-site Data — 现场数据

由在扩散分析所模拟场址附近运行的气象观测计划所采集的数据。

### OU — 输出路径标识

**英文：** OUtput

用于指定输出选项的输入控制文件命令所采用的两字符路径 ID。

### OU Pathway — OU 输出路径

用于指定某次模型运行输出选项的一组输入控制文件命令的统称。

### Overlay — 覆盖程序段

存放在磁盘中、仅在需要时才装入内存的一个或多个子程序。

## P

### Pasquill Stability Categories — Pasquill 稳定度类别

对大气扩散能力进行分类的体系。

该体系最初根据以下变量定义：

- 地表风速；
- 白天太阳辐射；
- 夜间云量。

此后也使用多种其他气象变量重新解释这些稳定度类别。

### Pathway — 功能路径

AERMOD 输入控制文件中的六个主要功能分区之一。

六条路径分别为：

| 路径 | 英文 | 功能 |
|---|---|---|
| `CO` | COntrol | 控制 |
| `SO` | SOurce | 污染源 |
| `RE` | REceptor | 受体 |
| `ME` | MEteorology | 气象 |
| `EV` | EVent | 事件 |
| `OU` | OUtput | 输出 |

### PC — 个人计算机

**英文全称：** Personal Computer

为个人使用而设计的一大类计算机，通常体积较小，可以放置在桌面上。

---

## Q

### Quality Assessment — 质量评价

对数据质量作出的判断。

### Quality Assessment Check — 质量评价检查

判断所报告的变量值是否合理。

另见 `Range Check`。

### Quality Assessment Message — 质量评价消息

当某个数据值被判定为可疑时，写入错误/消息文件中的消息。

### Quality Assessment Violation — 质量评价违规

数据值被判定为可疑的情况。

另见 `Range Check Violation`。

---

## R

### RAM — 随机存取存储器

**英文全称：** Random Access Memory

个人计算机中的随机存取内存。

### RAMMET — RAMMET 气象处理程序

用于法规应用的气象处理程序，可以处理：

- 每日两次的混合层高度；
- 逐小时地表气象观测。

处理结果可供以下扩散模型使用：

- AERMOD；
- CRSTER；
- MPTER；
- RAM。

### Range Check — 范围检查

判断某一变量是否处于预先定义的上限和下限范围内。

### Range Check Violation — 范围检查违规

变量值超出预先定义的上下限范围。

另见 `Quality Assessment Violation`。

### RE — 受体路径标识

**英文：** REceptor

用于指定受体位置的输入控制文件命令所采用的两字符路径 ID。

### RE Pathway — RE 受体路径

用于指定某次模型运行受体位置的一组输入控制文件命令的统称。

### Regulatory Applications — 法规应用

按照《空气质量模型指南》开展、涉及法规决策的扩散模拟。

《空气质量模型指南》作为经修订的美国《联邦法规汇编》40 CFR 第 51 部分附录 W 发布。

### Regulatory Model — 法规模型

经美国 EPA 法规管理部门批准用于法规工作的扩散模型。

具体而言，通常是被列入经修订的《空气质量模型指南》附录 A 的模型，例如 AERMOD。

### R-LINE — 研究型线源扩散模型

**英文全称：** Research LINE-source Dispersion Model

用于模拟近地面排放的研究型线源扩散模型。

---

## S

### SCRAM — 法规空气模型支持中心

**英文全称：** Support Center for Regulatory Air Models

美国 EPA 网站的一部分，用于发布：

- 空气质量扩散模型；
- 模拟技术指南；
- 相关资料。

### Secondary Keyword — 二级关键字

作为某一主控制文件关键字的参数使用的描述性英文关键字，用于指定某一具体选项。

### SO — 污染源路径标识

**英文：** SOurce

用于指定污染源输入参数和污染源组的输入控制文件命令所采用的两字符路径 ID。

### SO Pathway — SO 污染源路径

用于指定污染源输入参数和污染源组信息的一组输入控制文件命令的统称。

### Station Identification — 气象站标识

用于唯一标识气象站或站点的整数或字符串。

美国国家气候数据中心提供的以下数据格式中通常包含站点标识：

- 高空气象数据；
- 混合层高度数据；
- 地表气象数据。

对于以下数据，没有统一的标准站号：

- 现场气象数据；
- 卡片映像数据；
- 筛选数据。

用户可以使用任意整数型字符串作为其标识。

### Subdirectory — 子目录

位于根目录或其他目录之下的目录，用于组织个人计算机硬盘等存储介质中的文件。

### Surface Weather Observations — 地表气象观测

从地球表面观测得到的一组大气状态数据。

在美国，美国国家气象局会定期在选定站点采集这些数据。

### Surface Roughness Length — 地表粗糙度长度

根据近地面风速廓线外推时，风速降为零所对应的高度。

### Syntax — 语法

构成输入控制文件的各项输入内容的顺序、结构和排列方式。

具体而言，语法是管理下列输入要素放置方式的规则：

- 路径 ID；
- 关键字；
- 参数。

---

## U

### Unformatted File — 未格式化文件

未使用 FORTRAN `FORMAT` 语句写入的文件，有时也称为二进制文件。

### Upper Air Data (or Soundings) — 高空气象数据/探空资料

由气球携带的仪器获得的气象数据，用于提供远离地表位置处的以下信息：

- 气压；
- 温度；
- 湿度；
- 风。

---

## V

### Vertical Potential Temperature Gradient — 垂直位温梯度

位温随高度的变化率。

该参数用于模拟烟羽在稳定层中的抬升，并反映稳定温度逆温层的强度。

当垂直位温梯度为正时：

- 位温随离地高度增加而增大；
- 表明大气处于稳定状态。

---

## W

### Warning Message — 警告消息

当模型发现可能反映错误条件、但不会阻止后续处理的问题时，写入错误/消息文件中的消息。
