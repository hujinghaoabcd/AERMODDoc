# 关于项目

AERMODDoc 是面向中文用户的 AERMOD 在线参考文档。项目以 EPA 2023 年 10 月版用户指南为底本，建立了第 1—4 章、附录 A—E、站内搜索和自动部署结构。

## 当前状态

第二阶段已经将第 3 章 CO、SO、RE、ME、EV、OU 六条功能路径及附录 A—E 更新为完整逐条译文，不再仅保留摘要或示例性内容。

[查看第二阶段覆盖报告](./phase2-coverage.md)

## 翻译原则

1. 说明文字采用简体中文；
2. AERMOD、AERMET、AERMAP、SCRAM、NAAQS、PSD 等专有名称和缩写保留英文；
3. 控制文件路径标识、关键字、参数、文件名、变量名、程序文件名、Fortran 格式和模型原始输出保留英文；
4. 公式、单位、编号和交叉引用原则上保持不变；
5. 法规应用以 EPA 英文原文和主管机构要求为准。

## 参与完善

发现翻译、格式、链接或技术表述问题时，可在 GitHub 提交 Issue 或 Pull Request。建议注明所在章节、对应英文原文页码、建议修改内容及依据。
