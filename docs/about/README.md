# 关于项目

AERMODDoc 是面向中文用户的 AERMOD 在线参考文档。项目以 EPA 2023 年 10 月版《User's Guide for the AMS/EPA Regulatory Model (AERMOD)》（EPA-454/B-23-008）为底本，提供可检索、可链接、适合桌面端和移动端阅读的中文在线版。

## 当前状态

前置部分、第 1—4 章和附录 A—E 已全部进入网站。其中，第 3 章按 CO、SO、RE、ME、EV、OU 六条功能路径拆分，第 2 章保留完整教程和模型输出示例，附录 A、C、D、E 分别建立了表格、文件格式、逐项修订和术语级目录。

项目当前进入持续维护阶段，后续工作以纠错、术语优化、版本更新和可用性改进为主，而不是继续补录缺失章节。

[查看文档完成与质量报告](./phase2-coverage.md)

## 翻译原则

1. 说明文字采用简体中文；
2. AERMOD、AERMET、AERMAP、SCRAM、NAAQS、PSD 等专有名称和缩写保留英文；
3. 控制文件路径标识、关键字、参数、文件名、变量名、程序文件名、Fortran 格式和模型原始输出保留英文；
4. 公式、单位、编号和交叉引用原则上保持不变；
5. 中文术语在全站统一，章节编号、站内链接和页面锚点由自动化检查保护；
6. 法规应用以 EPA 英文原文、当前模型版本说明和主管机构要求为准。

## 自动质量控制

每次 Pull Request 和主分支构建都会执行：

- 章节与附录内容量和关键标记检查；
- 第 2—4 章及附录的编号结构检查；
- 正文“第 x.x 节”交叉引用检查；
- 中文核心术语一致性检查；
- VuePress 正式构建；
- 构建后站内链接与锚点检查；
- GitHub Pages 构件上传与部署。

## 参与完善
