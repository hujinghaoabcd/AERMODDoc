# 关于项目

AERMODDoc 是面向中文用户的 AERMOD 在线参考文档。本次重构以 EPA 2023 年 10 月版用户指南为底本，替换了仓库中未完成的早期译稿，并建立了完整的章节、附录、搜索和自动部署结构。

## 翻译原则

1. 说明文字采用简体中文；
2. AERMOD、AERMET、AERMAP、SCRAM、NAAQS、PSD 等专有名称和缩写保留英文；
3. 控制文件路径标识、关键字、参数、文件名、变量名、程序文件名、Fortran 格式和模型原始输出保留英文；
4. 公式、单位、编号和交叉引用原则上保持不变；
5. 法规应用以 EPA 英文原文和主管机构要求为准。

## 参与完善

发现翻译、格式、链接或技术表述问题时，可在 GitHub 提交 Issue 或 Pull Request。建议在问题中注明：

- 所在章节和小节；
- 对应英文原文页码；
- 建议修改内容及依据。
