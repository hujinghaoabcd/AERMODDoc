## 自动检查体系

GitHub Actions 在每次 Pull Request 和主分支构建时执行以下检查。

### 源文档完整性

- 必需页面是否存在；
- 各完整译文页面是否低于安全内容量阈值；
- 关键标题、关键字、表格、示例和稳定锚点是否缺失；
- Markdown代码围栏是否闭合；
- 是否出现常见未完成标记。

### 结构一致性

- 第 2 章22个编号小节和图2-1—图2-8；
- 第 3 章六条功能路径的全部真实编号；
- 第 4 章48条参考文献及编号连续性；
- 附录A—E各自的表格、条目、术语和侧栏结构；
- 正文中的“第 x.x 节”引用是否存在对应标题。

### 术语一致性

重点保护以下统一译法：

- Input Control File：输入控制文件；
- Source Group：污染源组；
- Receptor：受体；
- Meteorological Profile：气象廓线；
- Building Downwash：建筑物下洗。

### 构建后检查

VuePress生成最终HTML后，工作流继续检查：

- 站内链接目标是否存在；
- 页面内和跨页面锚点是否有效；
- 首页、侧栏、章节页和附录页能否正常生成；
- GitHub Pages构件能否成功上传。
