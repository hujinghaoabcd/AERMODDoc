## 本阶段完成内容

- 建立第 3 章关键字总索引；
- 按 CO、SO、RE、ME、EV、OU 六条功能路径组织导航；
- 将 160 余个关键字和主要次级选项链接到对应说明页；

- 增加自动页面存在性、代码围栏、链接和内容量检查；
- GitHub Pages 构建前自动执行文档检查。

## 尚未完成

当前页面是系统化在线参考版，并不等同于 275 页 Word 完整译稿的逐页无删减转换。下一阶段将继续补充：

- 第 3 章中的全部长篇参数说明和完整输入示例；
- 附录 A 的全部语法细节；
- 附录 C 中较长的原始输出记录；
- 图、表和跨章节交叉引用的进一步核对。

## 自动检查

GitHub Actions 在每次 Pull Request 和主分支构建前执行 `npm run docs:check`，检查：

- 第 3 章与附录必需页面是否存在；
- Markdown 代码围栏是否闭合；
- 本地链接是否指向有效文件；
- 是否存在常见的未完成或占位标记；
- 第 3 章和附录内容量是否低于当前在线版基线。

完整译文导入完成后，内容量阈值将同步提高。
