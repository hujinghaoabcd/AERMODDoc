## 使用提示

EPA 会更新模型可执行程序、源代码、测试案例、用户指南和实施指南。实际项目开始前，应核对：

1. 当前法规模型版本；
2. AERMOD、AERMET、AERMAP 的配套版本；
3. 主管机构认可的气象、地形和背景浓度处理方法；
4. 最新模型变更公告与勘误。
